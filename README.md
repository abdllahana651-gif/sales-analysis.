# السلام عليكم و رحمة الله و بركاته ابغا اتوظف محلل بيانات معي جدول 9800 و 18 عمود حسوي 3 طلبات عليه هنا

طلب1: تحليل المناطق: اكتشف المنطقة الأقل مبيعًا، وحدد المدن التي فيها ضعف في مبيعاتها، واقترح إجراءً لتحسين عدد المبيعات

طلب2: تحليل الفئات: اكتشف الفئة التي تعتمد عليها الشركة أكثر في المبيعات، وهل هناك فئة أداؤها ضعيف مقارنة بالبقية؟ قدم توصية

طلب3:تحليل النمو: اكتشف السنة التي فيها أضعف نمو في المبيعات، وحدد الأشهر التي كان فيها هاذا
